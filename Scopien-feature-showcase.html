04 — Agent Architecture

One gateway, many agents

🧩 Isolated Workspaces

Each agent has its own workspace, persona (SOUL.md, IDENTITY.md), memory, sessions, and skill set. No cross-contamination.

🔀 Smart Routing

Bind channels to agents. Route by sender, group, or channel account. Per-sender sessions or shared main session.

👶 Sub-Agents

Spawn background sub-agents for long tasks. They run in isolated sessions and report back when done. Parallel execution.

🔄 Session Management

Auto-compaction, session pruning, streaming, typing indicators. Sessions persist across restarts.

🧭 Model Flexibility

Anthropic, OpenAI, Ollama, Bedrock, OpenRouter, Qwen, Deepseek, and more. Swap models per agent or per session.

🛡️ Approval Flows

Elevated commands require user approval. Tool policies control what each agent can access. Safety by design.
